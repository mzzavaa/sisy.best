# SISY Best - Awards & Top Experts

Landing page for [sisy.best](https://sisy.best) - the SISY annual awards recognizing the most inspiring women voices.

## What is SISY Best?

The annual SISY 100 recognizes 100 women whose expertise, voice, and courage shape the conversations that matter most. Categories: Best Newcomer, Most Inspiring Voice, Changemaker of the Year, Industry Pioneer.

## Tech Stack

- [Hugo](https://gohugo.io) static site generator (v0.142.0 extended)
- Hosted on GitHub Pages with custom domain
- Inter + Playfair Display fonts
- Lucide icons

## Local Development

```bash
hugo server -D
hugo --gc --minify
```
